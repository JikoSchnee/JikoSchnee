<summary>About these statistics</summary>

The contribution calendar covers GitHub’s rolling past-year window, with weeks running Sunday through Saturday. It uses the daily counts and intensity levels returned by GitHub’s contribution calendar API, as visible to the repository workflow token; private activity may differ from your signed-in view. It is not limited to the repositories counted below.

Repository statistics include all public non-fork repositories, archived repositories and this profile. Stars are summed across these repositories. Language shares use GitHub’s byte counts, not proficiency. Updated daily; the last successful cards remain visible if an update fails. [Update history](https://github.com/JikoSchnee/JikoSchnee/actions/workflows/update-profile.yml)
